# Stylox | Ecommerce Website

Stylox is a **simple ecommerce website** designed to showcase products and provide users with a stylish online shopping experience. It is built using **HTML, CSS, and Google Fonts**, with basic navigation and layout.

---

## 🌟 Features

- Responsive **header with navigation menu**  
- Product showcase sections  
- Styled using **Poppins font** from Google Fonts  
- Integrated **Font Awesome icons** for UI elements  
- Hero section with call-to-action button  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Google Fonts (Poppins)  
- Font Awesome
